# 得意黑 Smiley Sans

内置字体为官方发布的 Smiley Sans v2.0.1，字体文件保持原样，不修改或重命名字体内部名称。

- 上游：https://github.com/atelier-anchor/smiley-sans
- 下载：https://github.com/atelier-anchor/smiley-sans/releases/download/v2.0.1/smiley-sans-v2.0.1.zip
- 字体文件：`SmileySans-Oblique.ttf`
- 许可证：SIL Open Font License 1.1，见 `OFL.txt`。

字体嵌入程序并仅在进程内加载，无需在系统中安装。安装版与便携版附带独立的字体许可证。
